# Kiwi modules: personal, documentation

This repository holds derlocke's own modules for kiwi-server. A *module* is one service of a
machine in a Kiwi network; these are the ones that are not built in. The repository's
[README](https://github.com/derlocke-ng/kiwi-modules-personal/blob/main/README.md) says how to
add them to a network and how to write one.
